                            🎯 QUICK COMMAND REFERENCE
================================================================================

After installing Git, run these commands:

1. Navigate to project:
   cd C:\Users\ishan\Documents\secure-upi-payment

2. Initialize Git:
   git init

3. Add all files:
   git add .

4. Create first commit:
   git commit -m "Initial commit: ScanX QR Payment Verification System"

5. Set main branch:
   git branch -M main

6. Add remote (REPLACE YOUR_USERNAME):
   git remote add origin https://github.com/YOUR_USERNAME/scanx-qr.git

7. Push to GitHub:
   git push -u origin main

For detailed instructions, see: GITHUB_SETUP.md
